# xk6-tlsauth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a minimal xk6 extension that adds per-request `tlsAuth` for HTTP and WebSocket on stock k6 until upstream PR #6506 merges.

**Architecture:** One Go module registers two JS import paths (`k6/x/tlsauth/http`, `k6/x/tlsauth/ws`).
A shared `internal/tlsauth` parser turns `{cert,key,password?}` into a `tls.Certificate`.
HTTP and WS modules each build a one-shot TLS client config from that certificate.

**Tech Stack:** Go 1.24+, `go.k6.io/k6/v2` (v2.3.0), `github.com/gorilla/websocket`, xk6, Go `testing` + `net/http/httptest`.

**Spec:** `docs/superpowers/specs/2026-09-29-xk6-tlsauth-design.md`

## Global Constraints

- Module path: `github.com/XavierChevalier/xk6-tlsauth`
- Import paths: exactly `k6/x/tlsauth/http` and `k6/x/tlsauth/ws`
- Keep v1 minimal: no batch, cookies, redirects tuning, compression, digest/ntlm, WHATWG websockets
- Prefer small files; shared PEM parsing only in `internal/tlsauth`
- TDD: failing test before implementation for each behavior
- Each full sentence in Markdown docs on its own line (project AGENTS preference)

Create `internal/tlsauth/parse.go`:

```go
package tlsauth

import (
	"crypto/tls"
	"fmt"

	"gopkg.in/guregu/null.v3"

	"go.k6.io/k6/v2/lib"
)

// Parse builds a client certificate from a JS tlsAuth object:
// { cert: string, key: string, password?: string }.
func Parse(v any) (*tls.Certificate, error) {
	raw, ok := v.(map[string]any)
	if !ok {
		return nil, fmt.Errorf("tlsAuth must be an object, got %T", v)
	}
	certStr, ok := raw["cert"].(string)
	if !ok || certStr == "" {
		return nil, fmt.Errorf("tlsAuth.cert must be a non-empty PEM string")
	}
	keyStr, ok := raw["key"].(string)
	if !ok || keyStr == "" {
		return nil, fmt.Errorf("tlsAuth.key must be a non-empty PEM string")
	}
	auth := &lib.TLSAuth{
		TLSAuthFields: lib.TLSAuthFields{
			Cert: certStr,
			Key:  keyStr,
		},
	}
	if password, exists := raw["password"]; exists && password != nil {
		passwordStr, ok := password.(string)
		if !ok {
			return nil, fmt.Errorf("tlsAuth.password must be a string")
		}
		auth.Password = null.StringFrom(passwordStr)
	}
	return auth.Certificate()
}
```

If `lib.TLSAuth` / password decrypt pulls too many deps for a tiny extension, replace the body with `tls.X509KeyPair` plus the same decrypt helper copied from k6 `lib/options.go` (keep behavior identical; prefer reuse first).
